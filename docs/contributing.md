# Contributing guide

The authoritative contribution policy and setup are in [`CONTRIBUTING.md`](../CONTRIBUTING.md).
Before opening a pull request, also read [Architecture](architecture.md) and [Testing](testing.md).

Contributions must keep scientific and mechanical changes reviewable, add deterministic
regression tests for defects, preserve documented output interfaces, update user-facing guides,
and use only synthetic non-identifying fixtures. Scientific formula changes require explicit
rationale and an accepted representative-data comparison. Private paths, manifests, laboratory
data, manuscript data, and generated high-resolution panels are out of scope for commits.
